Tentang Saya

Halo! Saya Zain Fadila, seorang mahasiswa aktif Program Studi Sistem Komputer di Universitas Pamulang (UNPAM) Kampus Serang.

Sebagai mahasiswa Sistem Komputer, fokus saya mencakup pemahaman mendalam tentang integrasi antara perangkat keras (*hardware*), perangkat lunak (*software*), infrastruktur jaringan dasar, serta keamanan sistem digital. Saya terbiasa menangani diagnosa masalah teknis (*troubleshooting*), melakukan konfigurasi sistem operasi, dan mendokumentasikan proses teknis secara terstruktur.

Selain akademis, saya aktif berorganisasi di Himpunan Mahasiswa Sistem Komputer (HIMASIKOM) sebagai *IT Support Liaison* dan telah memimpin proyek pengabdian masyarakat (PKM) berfokus pada edukasi keamanan siber. Saya siap memberikan kontribusi nyata, belajar cepat di lingkungan kerja profesional, dan siap menjalani program magang (*internship*) di bidang IT Technical Support, Systems Support, maupun Digital Solutions.
